DEPLOYMENT

      

        
一份代码，
三种跑法。

        
线上、容器、本机，同一个 /mcp 地址，同一份 logic。不装全局依赖，不动系统环境。

      

      

        

          
01
VERCEL
线上主线

          
推送到 main 即部署，同一个地址同时提供网页、REST 与 MCP。

          
git push origin main

          
需要：一个 GitHub 仓库 · 一个 Vercel 账号

        

        

          
02
DOCKER
零污染

          
容器里跑完整服务，宿主机不需要 Node，也不留下任何东西。

          
docker compose up --build

          
需要：Docker Desktop 或 Docker Engine

        

        

          
03
本地
调试友好

          
依赖只装进项目目录，删掉 node_modules 就等于卸载干净。

          
npm install && npm run dev

          
需要：Node.js 24 · 无全局安装
