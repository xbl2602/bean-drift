# 整月地形遮挡与一年统计：口径、数据随网站发布

- **提出人**：`xbl2602`（口径是 `xbl2602` 本人在对话里选定的）
- **状态**：采纳。解决 TODO Q1；推进 Q4、Q5（见"还没解决的"）。

## 决定了什么

1. **指标口径（解决 Q1）**
   - "可见"：太阳或地球圆盘的**上缘**高于地形地平线（圆盘露出任何一部分就算可见）。
   - 统计期：**2030-01-01T00:00:00Z 起 8760 小时，逐小时取样**，不随查询时刻变。
   - L4 最长断电、L5 最长断信号：统计期内**最长的单次**不可见（小时）。
   - L6 平均断电时间：统计期内**所有**连续不可见时段的**平均时长**（"按次平均"）。
   - L7 平均单次信号时间：统计期内**所有**连续地球可见时段的平均时长。
   - 另外存太阳可见比例、地球可见比例、两者同时可见比例。
   - 被统计期开头、结尾截断的时段，按截断后的长度计入。
2. **分辨率**：整月地图 0.25°（1440×720，约 7.6 km 一格）；地形来自 LOLA 全月 DEM `LDEM_64`（473.8 m/像素）。地平线 32 个方位、射线最远 300 km、球形月球。
3. **数据随网站发布**：产物约 55 MB（最大单文件 34 MB），放在 `public/data/v1/`，进 git，随 Vercel 部署；API/MCP 读同一份文件（`next.config.ts` 的 `outputFileTracingIncludes` 把它们打进对应函数包）。**不另建数据仓库、不用 CDN、不用 R2**。
4. **点位接口**：`GET /api/point`、MCP、`POST /api/compare` 的 `terrain`、`visibility`、`yearStats` 三组现在是真实数据；`yearStats` 和 `visibility` 用该点的地平线剖面现算（本机生产模式实测：一次 `/api/point` 请求约 0.1 秒，10 个点的 `/api/compare` 约 0.5 秒），新增字段 `meanOutageH`（L6）、`meanVisibleWindowH`（L7）。读不到数据文件时降级成 `status: unavailable`，接口仍返回 200。
5. **流水线**：`pipeline/` 里 `npm run data` 一键重跑（约 70 秒），怎么跑见 `pipeline/README.md`。星历只用 `src/core/ephemeris` 这一份（新导出 `bodyFixedSunEarth`，原有的 `skyAtLatLon` 数值不变）。

## 为什么

- 之前做过的预计算（旧演练仓库）已有完整的 DEM 和流水线骨架，这次是**沿用并修正口径**，而不是从零重做。修正的地方：按"上缘可见"而不是"圆心可见"；改成 2030 全年逐小时；增加 L6、L7；星历改用核心里同一份，避免两份星历。
- 单个文件小于 50 MB、总量约 55 MB，在 GitHub 和 Vercel 的限制之内；不需要拆块分发或外部存储，部署路径最简单、没有限流问题。
- "按次平均"比"平均到整年"更能说明"一次断电大概多久"，对任务规划更有用。

## 备选方案

- 圆心可见 / 圆盘完全露出才算可见：圆心口径会低估日照；完全露出口径会严重低估。上缘口径与 NASA LOLA 平均可见性产品同口径，便于对照。
- 18.6 年周期或最坏年份：计算量成倍增加，且没有定"最坏"的标准，放到以后。
- 更细的格子（如 0.125°，约 3.8 km）：horizon 文件会到约 136 MB，超出单文件舒适范围，需要拆块；这次不做。

## 还没解决的（不要当成已完成）

- **分辨率只是"整月概览"级别**，不是着陆点尺度。比如南极 Shackleton 这种直径约 20 km 的撞击坑，在 7.6 km 的格子里只占几个格子；格子内部的地形不参与地平线计算。
- **没有对照 NASA 官方的 LOLA 平均可见性产品逐点核对**；只做了预计算与运行时现算的一致性检查和已知地点合理性检查。
- 只算了 2030 一年，不是最坏年份。
- Q4：现在的结论是"这个规模放 Vercel 静态文件就够"；**更高精度的全月地形（约 8.5 GB）仍未拍板**。

- 返回结构变化：`yearStats.<sun/earth>` 新增 `meanOutageH`、`meanVisibleWindowH`；`terrain`、`visibility`、`yearStats` 有真实值。字段已在 `docs/SHARED_INTERFACES.md` 第 2 节更新，新增 2.5.1 整月地图的文件格式。
