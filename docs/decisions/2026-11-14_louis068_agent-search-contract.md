## 提议的 HTTP 接口

`POST /api/agent`，只接受 JSON `{ "message": "..." }`，未知字段拒绝。
消息去除首尾空白后 1–2000 字符；请求体最大 8192 字节；首版无客户端历史。
请求完成后返回 JSON，不做流式输出。

成功：`{ "answer": "...", "sources": [{ "tool": "list_presets", "input": {}, "result": {} }], "mode": "live" }`。
sources 保留已成功执行工具的实际结果与 provenance，不能用模型自写的来源替代。
工具未执行时 sources 为空；界面不能把没有来源的回答标成已验证计算。

错误保持项目通用 `{ "error": { "code": "...", "message": "..." } }` 格式：
400 输入无效，413 请求过大，429 配额耗尽，503 模型/限流未配置或不可用，504 超时。
错误文案固定，不回传供应商响应、密钥、堆栈、内部路径。响应禁用缓存。

## 提议的内部依赖

由路由注入依赖，feature 不读取环境变量，不直接访问模型网络、数据库或文件系统。

1. `tools`：使用现有 `ReadTool` 类型和注册表，只允许
   `get_point_conditions`、`compare_points`、`list_presets`。每次调用先验证名字、只读标志和 zod 参数。
2. `complete({messages, tools, maxOutputTokens, signal})`：由 `src/lib/llm/` 提供。
   返回 `{content: string, toolCalls: [{id: string, name: string, arguments: unknown}]}`。
   适配器负责 DeepSeek 协议转换和响应结构校验；messages 支持 system/user/assistant/tool，工具回复关联 call id。
   不支持的模型响应判为失败，不猜测内容。具体 TypeScript 类型由双方在 SHARED_INTERFACES 定稿。
3. `reserveQuota({signal})`：每个有效请求在首次模型调用前原子预留一次，返回
   `{allowed: true}` 或 `{allowed: false, retryAfterSeconds: number}`。
   建议由 Supabase 原子函数同时检查全站每分钟 5 请求、每天 UTC 100 请求。
   存储失败必须拒绝付费调用。计数不能放进进程变量；并发和跨实例必须共享。
   这只是请求限额，不等于美元费用上限；每请求可有多次模型调用。

建议硬限制：最多 4 次模型调用、总共 8 次工具执行、每次模型输出最多 1200 tokens、
每次工具结果最大 64 KiB、总请求 25 秒。超时 signal 传播至模型与限流服务。
不自动重试模型请求，避免重复计费。工具结果超限时返回安全错误，不能截断成看似完整的数据。

## 回答与数据规则

- 自然语言入口只搜索已有工具可提供的月球数据，不承诺互联网“搜索所有东西”。
- 地点名先查预设点；找不到就请求经纬度，不编造坐标。
- 时间使用 UTC；问题没指定日期时说明使用的查询时间。
- 保留度、km、UTC 和来源。现有星历是解析近似，不称为 SPICE 或任务级精算。
- 球面地平线可见不等于真实山地无遮挡、稳定通信或太阳能发电保证。
- terrain/yearStats 为 null 时明确未接入；不伪造山地、全年窗口、最佳地点排序。
- 模型和工具内容不可信；拒绝未注册工具；没有 shell、网络浏览、文件或数据库工具。
- 测试模型替身仅在自动测试使用，不给公共请求增加绕过限流的 test 参数。

## 验收清单（待实现后运行）

1. 列出预设点：实际调用 list_presets，回答来源匹配工具结果。
2. 单点查询与多点比较：参数通过原有 schema，结果与现有 API 相同。
3. 非法经纬度、无 Z 的时间、超过十点：工具不执行。
4. 未知地点：请求用户提供坐标；未接入地形与全年统计：明确说明。
5. 空问题、超长文本、未知字段、过大请求：模型和计费限流均不调用。
6. 未注册工具、写工具、重复调用 id、畸形模型响应：安全失败。
7. 循环调用：达到工具/轮次限制就停止，不触发额外付费调用。
8. 限流拒绝、限流超时或故障：零模型调用；两实例并发不能突破共享额度。
9. 模型超时/服务失败：返回固定安全错误，不泄露上游文本。
10. 本地无密钥运行单元测试；xbl2602 配置服务端密钥后再做一次真实请求与预算验证。
11. 产品页面 → /api/agent → 模型 → 注册工具 → 页面来源显示的完整联调。
