# decisions/：一条决定一个文件

**为什么这样做**：5 个人（还有各自的多个 AI）同时记录"我们决定了什么"，如果都往同一个文件里写，必然冲突。所以**一条决定一个文件，文件名自带日期和作者，永远不会重名、不会互相覆盖**。

**怎么写**

1. 复制 [_TEMPLATE.md](_TEMPLATE.md)，改名为 `YYYY-MM-DD_<你的GitHub用户名>_<主题>.md`，例如 `YYYY-MM-DD_louis068_point-api-fields.md`。
2. 填好：决定了什么、为什么、备选方案、需要谁确认。
3. 随你的 PR 一起提交。
4. `xbl2602` 定期把已采纳的决定整理进 [../DECISION_LOG.md](../DECISION_LOG.md)，并给它编号。

**什么时候该写**：换技术、改架构、改规则、改范围、改接口、定指标公式、选数据来源……任何"以后有人会问当时为什么这样"的事。拿不准就写，一条只要几句话。

**提议改共享区**（`src/core/`、接口约定、`AGENTS.md`）也写在这里，由 `xbl2602` 批准后他来改。
