## 3. 参赛规则

**3.1 选题**
- 共 14 个挑战，任选其一："you can choose any one of these 14 and make a 30 second video of this problem solution"。
- 官网每个挑战有背景、目标、难度（beginner / intermediate 等）、资源和已注册团队列表。
- 举例展示的挑战是 "Abandoned but Not Forgotten"，难度为 intermediate。有些题 "very beginner"，"you can choose any, no problem"。
- 其他能辨认的题目名（转录大多不完整 ⚠️）：Flame in Free Fall、Interplanetary Survival Guide、Martian Map、CLPS Lunar Mission Browser、Junior astronaut mission trainer、Mission design game 等。
- 某个挑战下目前已有 1,409 个团队注册；你选定挑战后，团队名会显示在对应列表里。

**3.2 提交物：30 秒视频**
- 最长 30 秒："Your video might be smaller but 30 seconds is the maximum."
- 视频要覆盖：选了哪个挑战、怎么解决、用了什么数据、方案说明。
- 主讲人给出的结构：先自我介绍（名字、队名和所选题目）；然后讲方案名称、带来的价值、解决的问题、原理、原型/图像、数据和技术如何支撑；最后讲未来影响。⚠️ 各段的具体秒数转录不清。
- 视频应是动态的："your video should be a live one, so that it looks like a running, continuous video. A motion video will get more impression and marks."
- 提交方式是在线提交。样例视频会在 WhatsApp 子群里分享。

**3.3 数据**
- 用 NASA 数据有加分："If you use a NASA dataset … [and say] in your video … you get some additional marks"；"It will give additional marks"。
- 可用来源：data.nasa.gov 和 api.nasa.gov。
- 不强制用 NASA 数据："You don't have to use any NASA datasets and also mention in your video which dataset you are using."
- 今年有 17 个合作航天机构，任选其一的数据集都合规：Angola、Argentina、Bahrain、Brazil、Canada、European、Indian、Italian、Japan、Korea、Nigeria、Paraguay、Senegal、Spanish、Turkish、UAE、United Kingdom。
- 建议做法："connect them with your project, build an API with it if you can, and show this in your project demonstration"。

**3.4 版权、AI 与素材**
- "You cannot use any copyright material. This is strictly mentioned."
- 不能用 YouTube 等来源的版权素材；别人的素材需有明确许可。
- AI 生成内容：允许但要说明。"with valid reason, with prompts explained … you can use it"；问答里："Yes, you may use AI images. [You] need to mention that it is generated."
- 库存素材（stock）：先建议自己做，"ideal case if you intend to win you should do everything on your own"；如果用，"must use royalty-free ones, must provide a disclaimer"。
- 付费素材：可以用，但要 "proper credits, disclaimers and reasons"。

**3.5 技术与组队**
- 编程平台不限："There is no restriction — C++, C, Java or any Python coding"。
- 可以单人参加，但更建议组队："You can also participate alone, but team-wise would be better"。
- 一句提到 "your team as five members" ⚠️，不是明确的人数规定。
- 队名建议格式：university name + underscore + team name。

Global nominees → global finalists → honorable mentions → global winners，"step by step serially"。

## 5. 报名流程（主讲人演示）

1. 打开 spaceappschallenge.org，点 Sign up，创建账号（全名、用户名、邮箱、密码，头像可选，居住地选 Malaysia，勾选条款和验证）。
2. 登录后选择 "Register for … NASA events"，再选 hackathon。
3. 在本地活动里搜索 Kuala Lumpur 并选择。
4. 加入或创建团队。
5. 提交项目，完成参赛者问卷。

- 每位成员各自创建账号；"first team leader will create an account"。
- 邮箱可以直接当用户名。
- 年龄组别：10–12 岁、13–17 岁、大学生（上限转录不清 ⚠️）；其中第一组被说成 "secondary" ⚠️，可能是 primary。
