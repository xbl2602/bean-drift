# logs/：每个人自己的工作日志

每个人在 `docs/logs/<你的GitHub用户名>/` 下写自己的日志，**一天一个文件** `YYYY-MM-DD.md`，例如 `docs/logs/chanjy0806/YYYY-MM-DD.md`。文件夹第一次写的时候自己创建。

**为什么分开**：5 个人（和各自的多个 AI）同时写日志，如果共用一个文件一定冲突。各写各的文件夹，永远不会碰到别人的文件。

**写什么**（每天几句话就够，让 AI 帮你写也行）：

- 做了什么、为什么这样做
- 没做完的是什么、卡在哪
- 对别人有影响的事（比如"我改了某个接口"）

**什么时候写**：收工前。重要的"决定"另外写到 `docs/decisions/`。
